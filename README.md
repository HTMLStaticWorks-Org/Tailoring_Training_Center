# Velora

A multi-page fashion academy and professional tailoring training institute website designed for beginners, women entrepreneurs, students, homemakers, and aspiring fashion designers.

## Pages Included
1. `index.html` – Home
2. `about.html` – About Our Institute
3. `courses.html` – Training Courses
4. `batch-timings.html` – Batch Timings
5. `gallery.html` – Student Works & Training Gallery
6. `contact.html` – Contact & Enrollment

## Design System
- **Color Palette**: Deep Burgundy (`#702D45`), Dusty Rose (`#C58A9A`), Champagne Gold (`#C6A15B`), Warm Ivory (`#FAF7F2`), Pure White (`#FFFFFF`), Espresso Charcoal (`#30272B`), Muted Mauve (`#786B70`), Soft Rose Border (`#E9DDE0`).
- **Typography**: `Playfair Display` (Headings & Italic Highlights) and `DM Sans` (Body, Navigation, & SemiBold Buttons).
- **Tech Stack**: Semantic HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5 via CDN, Bootstrap Icons, Google Fonts CDN.
